The RPM installation also includes ca-certificates, curl, tar, gzip, pip, setuptools, GCC, Git, Clang, OpenSSL, the Node.js runtime libraries, and wget. Go source builds target Linux amd64.

Runtime defaults

The Dockerfile creates user neo with UID/GID 2000 and sets HOME=/home/neo. It does not set a USER instruction, so Docker runs commands as root by default. Use --user to override this when writing files into a host-mounted directory.

The runtime and CI pipeline both pin Trivy to 0.76.1. When upgrading, update the Dockerfile build argument and all Trivy image references in the build workflow together, then validate CycloneDX generation and license reporting.
