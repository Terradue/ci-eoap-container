# ci-eoap-container

`ci-eoap-container` provides a single CI runtime for validating Common Workflow
Language (CWL) documents, generating documentation and metadata, scanning images,
and publishing OCI artifacts.

## Choose your path

This documentation follows Diátaxis, with four types of content for different needs.

| Your goal | Start here |
| --- | --- |
| Learn by completing a small example | [Your first CWL validation](tutorials/first-workflow.md) |
| Complete a specific task | [Build and run](how-to/build-and-run.md), [transform CWL](how-to/transform-cwl.md), or [publish artifacts](how-to/publish-artifacts.md) |
| Look up tools and build behavior | [Included tools](reference/tools.md) and [CI pipeline](reference/ci.md) |
| Understand the design | [CWL and OCI](explanation/cwl-and-oci.md) and [license evidence](explanation/license-evidence.md) |

For image operations, see [scan and push images](how-to/scan-and-push.md).
For attribution files, see [retrieve notices and review licenses](how-to/license-review.md).
